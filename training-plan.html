14-Week Hybrid Strength + Half Marathon Build  ·  Aug 16 – Nov 15, 2026

Training Plan

Overview

Weekly mileage and lifting by day, building toward the Run to Feed the Hungry Half Marathon on Nov 14. Focus is aerobic base and durability while holding onto strength — speed work is deferred to next season. Monday/Wednesday pair a morning strength session with an evening easy run; Tuesday is 30 min cross-training (20 in the taper, off in race week); Thursday is an easy run with strides; Friday is upper-body strength only plus optional easy cross-training, no run, to protect Saturday's long run; Saturday carries the long run, with periodic cutback weeks along the way; Sunday is rest. Weekly mileage is set from Saturday's long run, with Monday/Wednesday/ Thursday splitting the remainder by formula.

Easy Running & Strides

No quality (tempo or interval) work this cycle — everything is easy effort aside from short strides. Quality sharpens pace but is also where most running injuries happen, so with a running base but no half-marathon experience yet, this season trades a faster ceiling for durability and aerobic volume; quality can return once that base is established.

Thursday's easy run includes 4–6 × 15–20 second relaxed strides near the end, full recovery walk between each — turnover and running economy, not effort, with almost no fatigue cost. Strides start once running is fully re-established in Week 4 (Weeks 1–3 are still on the injury recovery ramp above) and run through the rest of the plan, dropping out only in the taper and race week so the priority shifts entirely to arriving fresh.

Strength Program

Three sessions per week: Monday (full-body, heavy, barbell — back squat, deadlift, alternating press, row), Wednesday (lower-body, moderate, dumbbell/band), and Friday (upper-body only, moderate, dumbbell/band — no leg loading, so soreness doesn't land on Saturday's long run). Every session closes with the same lower-back/hip core routine.
