21-Week Half Marathon Build  ·  Jun 28 – Nov 15, 2026

Training Plan

Overview

Weekly mileage by day, building toward the Run to Feed the Hungry Half Marathon on Nov 14. The first three weeks program strides only on Wednesdays. From there, Wednesdays rotate intervals and hills on Build weeks, while every Deload week gets tempo, the lowest-novelty stimulus.

Wednesday structure: Strides only through week three. From week 4 on, intervals and hills alternate on Build weeks while every Deload week gets tempo — the lowest-novelty session, easiest to control on a lighter week. Intervals are run at 10K effort (9:35–9:45/mi) — a notch easier than 5K effort. Hill reps stay in a 30–45 sec range throughout on whatever grade is available, progressing by rep count only, and are placed only on Build weeks. Race weeks override the structure with an easy run + strides — the race is that week's quality session. Taper week (Nov 8) holds intervals at the same effort but fewer reps. Paces are derived from a 9:25/mi 5K (Jun 3) and a ~12:00/mi easy baseline.

Strength Program

Two sessions per week, Tuesday and Friday, with a fixed exercise list that stays the same for the whole plan — only sets, reps, and load change by phase, and every week spells out exactly which press variation to use, so there's nothing to track. Tuesday is full-body: squat, Romanian deadlift, a press, and lunges, plus a core/hip finisher. Friday is upper body: a press, curls, banded rows, and banded lateral raises, plus the same core/hip finisher. Fixed exercise list, explicit each week: Tuesday and Friday keep the same exercise categories for the entire 21 weeks — Tuesday is squat, Romanian deadlift, a press, lunges, and the core/hip finisher (lateral leg raise, clamshell, dead bug, push-up); Friday is a press, DB curl, banded row, banded lateral raise, and the same core/hip finisher. The press variation (shoulder or bench) is called out explicitly every single week rather than left to "alternate" — Tuesday and Friday always run opposite choices in the same week, so both movements get even volume and there's nothing to remember. Only sets, reps, and load change week to week — the exercises themselves never get swapped out.

Weeks 1–3 (Technique): Bodyweight and light dumbbell only, same exercise list, higher reps — this is about grooving the squat, hinge, press, and lunge patterns before adding load.

Weeks 4–14 (Foundation/Build): Working sets and progressive load, but only one of squat or Romanian deadlift progresses on any given Tuesday — the other holds at a steady, controlled weight. Squat-emphasis and deadlift-emphasis weeks alternate, so you never add load to both lower-body lifts in the same session. Friday stays zero leg loading, because Friday sits the day before Saturday's long run and lower-body soreness peaks 24–48 hours after a session — exactly the window that would otherwise land on the long run.

Week 15 exception: Tuesday carries a 3-mile run that week instead of a rest/lift day, so Tuesday's strength session is dropped entirely rather than stacked with the run — Friday runs the same exercise list at reduced sets instead of two full sessions.

Weeks 16–19 (Peak): As running volume climbs to 22–26 mi/week, strength shifts to maintenance — same exercise list and working weight, fewer sets, squat and RDL both held steady rather than progressing. The goal is holding onto what's been built, not progressing further, while running takes priority.

Week 20 (Taper) and Week 21 (Race): Taper week runs one light, single-set pass through the full Tuesday list just to feel normal, nothing more — no Friday session, so legs and upper body both stay fresh. Race week skips strength entirely — the race is that week's only output.
