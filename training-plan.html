16-Week Hybrid Strength + Half Marathon Build  ·  Aug 2 – Nov 15, 2026

Training Plan

Overview

Weekly mileage and lifting by day, building toward the Run to Feed the Hungry Half Marathon on Nov 14. Focus is aerobic base and durability while holding onto strength — speed work is deferred to next season. Monday/Wednesday pair a morning strength session with an evening easy run; Tuesday is 30 min cross-training (20 in the taper, off in race week); Thursday is an easy run with strides; Friday is upper-body strength only plus optional easy cross-training, no run, to protect Saturday's long run; Saturday carries the long run on a four-week rhythm with a cutback every fourth week; Sunday is rest. Weekly mileage is set from Saturday's long run, with Monday/Wednesday/ Thursday splitting the remainder by formula.

Easy Running & Strides

No quality (tempo or interval) work this cycle — everything is easy effort aside from short strides. Quality sharpens pace but is also where most running injuries happen, so with a running base but no half-marathon experience yet, this season trades a faster ceiling for durability and aerobic volume; quality can return once that base is established.

Thursday's easy run includes 4–6 × 15–20 second relaxed strides near the end, full recovery walk between each — turnover and running economy, not effort, with almost no fatigue cost. Strides run throughout the plan, dropping out only in the taper and race week so the priority shifts entirely to arriving fresh.

Strength Program

Three sessions per week (Monday, Wednesday, Friday) with a fixed exercise list for all 16 weeks — only sets, reps, and volume change by phase. Monday: full-body, heavy, barbell (back squat capped at 3 sets, deadlift capped at 1 set, press alternating weekly — bench press on odd weeks, shoulder press on even weeks — row) — the most recovery runway before Saturday's long run. Squat and deadlift set caps limit systemic (CNS) fatigue, the same approach used by Starting Strength and StrongLifts 5×5. Wednesday: lower-body, moderate, dumbbell/band (squat variation alternating goblet/Bulgarian split week to week, single-leg RDL, lunges, calf + tib raise superset). Friday: upper-body only, moderate, dumbbell/band (DB bench press, DB shoulder press, DB curls, face pulls, banded rows), no leg loading, sitting the day before the long run since lower-body soreness peaks 24–48 hours later — face pulls cover rear-delt/ external-rotation balance against the week's pressing volume, and skull crushers were dropped since bench and shoulder press already load triceps enough. Every session closes with push-ups and two specific core exercises. On cutback weeks (4, 8, 12), Monday and Wednesday drop one set from every lift; Friday stays unchanged since upper-body work doesn't compete with running-leg recovery. Click any Monday, Wednesday, or Friday cell in the grid for that week's exact sets and reps.

Core, prescribed exactly each session: one glute activation/hip stability exercise + one stability exercise, rotated across the three strength days rather than repeated — Monday: hip thrust + side plank. Wednesday: clamshells + dead bug. Friday: lateral leg raise + heel taps. Same pairing every time a given day comes up, all cycle long. Push-ups run separately every Monday, Wednesday, and Friday — an active plank, so anti-rotation/anti-extension demand is already covered without a dedicated Pallof-press-style exercise.

  • Weeks 1–4 (Base): Full volume — heaviest squat and deadlift numbers while running mileage is still low. Week 4 is a cutback week: one set lighter on Monday and Wednesday.
  • Weeks 5–8 (Build): Intensity holds; lower-body sets trim slightly as mileage climbs, since mileage drives this season's fitness. Week 8 is a cutback week: one set lighter on Monday and Wednesday.
  • Weeks 9–12 (Peak Build): Lower body trims further on Monday and Wednesday; upper body (Friday) unchanged; core stays in every session as insurance against running-related hip and knee issues. Week 12 is a cutback week: one set lighter on Monday and Wednesday.
  • Weeks 13–14 (Peak): As the long run peaks at 11–12 miles, lower body drops to a maintenance dose (same exercises, held load, minimal sets) and progression caps deliberately; upper body unchanged.
  • Week 15 (Taper): One light pass through the full list on all three days, volume cut 30–50%.
  • Week 16 (Race): Strength drops out entirely — the race is the week's only output.
